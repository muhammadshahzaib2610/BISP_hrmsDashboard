# BISP_hrmsDashboard
During my internship, I worked on the BISP_hrmsDashboard, a web-based Human Resource Management System developed to streamline HR operations. My responsibilities included assisting in the development and maintenance of dashboard modules, managing employee records, implementing database functionalities, and supporting attendance and leave management features. I worked with ASP.NET Core MVC, C#, and SQL Server to enhance system functionality, improve data management processes, and ensure a user-friendly experience for HR staff. This project helped me gain practical experience in web application development, database management, debugging, and software development best practices.

--Responsibilities--

1. Assisted in developing HRMS dashboard modules.
2. Worked with ASP.NET Core MVC and C#.
3. Performed SQL Server database operations.
4. Managed employee data and records.
5. Supported attendance and leave management features.
6. Fixed bugs and improved system functionality.
7. Tested and maintained application performance.
8. Collaborated with team members during development and deployment.
